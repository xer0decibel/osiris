OSIRIS FIELD KIT

Offline reference library, and a live intelligence map when there is a connection.

Read now — works on anything

Field references HTML First aid, water, shelter, signalling, repair. Reflows to fit a phone screen — start here rather than the PDFs. Same references PDF Archival originals, including the field manuals. Page layout is fixed, so they read poorly on a small screen — use these on a laptop or to print.

The full library

Wikipedia and reference archives Encyclopedia, medical, repair and appropriate-technology archives in .zim format. These need a reader — see below. Open the library if Kiwix is running Works once kiwix-serve is started, or on the booted drive where it starts by itself. Dead link otherwise — that is expected.
On a phone? Install Kiwix from the App Store or Play Store, then open the .zim files from this drive inside it. Do this before you need it — the drive cannot install anything, and neither can this page.

The live map

OSIRIS dashboard needs a computer Aviation, maritime, fires, weather radar, CCTV, radio and TV. The map works with no connection; the layers fill in when there is one.

If it is not already running, start it from this drive — nothing is installed, and nothing is written to the host:

portable\windows\node.exe osiris\server.js
./portable/linux/node osiris/server.js
./portable/macos/node osiris/server.js
A phone can read everything above, but it cannot run the dashboard — there is no way to run a server from a drive on iOS or Android. Plug this into a computer for the live map.

Then open localhost:3000.

This drive is pinned to its offline basemap, so it never reaches for a map server it cannot get to. Everything else fills in on its own once you have a connection — there is nothing to switch.

Boot from this drive

For a machine that is switched off, is not yours, or that you would rather not trust. Restart it, open the boot menu — usually F12, F11, ESC or DEL during startup, and Option on a Mac — and pick this drive. Nothing is written to the computer's own disk.

Wikipedia and reference archives via Kiwix (openZIM). Basemap from Natural Earth, public domain. Fire, weather and hazard data from NASA, NOAA, USGS and NIFC.
Nothing on this page loads from the internet, so it works exactly the same on a dead network.
